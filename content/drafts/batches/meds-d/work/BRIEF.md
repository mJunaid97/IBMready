# Shared brief for meds-d author agents (first pass)

Deliverable for your medicine <id>:
 1. work/<id>.entity.json  = the full medication entity (all gate fields, string-list style, + `article` block: 4-6 sections of 110-220 words each, 3-6 faqs (a >= 60 chars, q ends with ?), 5-7 keyFacts; article 600-900 words total; plain paragraphs, no markdown).
 2. ledgers/<id>.ledger.json = list of {"where","sentence","basis":"excerpt|textbook","urls":[...],"note"} for EVERY sentence kept in the entity (summary, usedFor items, howItWorks, onset, each sideEffects/cautions item, monitoring, regimenNote, each article paragraph sentence, each faq answer, keyFacts values). `where` e.g. "summary", "usedFor[1]", "sideEffects.serious[0]", "article.sections[2].body", "article.faqs[1].a".
 3. If you own a new drug class (see list below): work/class-<classid>.json (entity in the style of content/drug-classes.json: name, aliases, summary, mechanism, members, cautions, classEffects, anatomy, conditions, medications, references (>=2, official host), urlAliases, physiology/terms optional) and its ledger ledgers/class-<classid>.ledger.json. Keep the class page short and only from retrieved text.
Rules: write from RETRIEVED text only (WebSearch with allowed_domains e.g. ["nhs.uk","nice.org.uk","medlineplus.gov","ncbi.nlm.nih.gov","medicines.org.uk","gov.uk","bnf.nice.org.uk","cks.nice.org.uk","ukhsa.gov.uk"]; use nhs.uk not www.nhs.uk). No doses, dosing schedules, durations-of-course numbers, cut-offs in prose. Describe, do not instruct (no "you should/stop taking"). UK English. Never "safe". Any urgency mention names the route to care (999/A&E emergency; NHS 111 or GP same day; GP appointment routine). Do not copy source sentences; paraphrase. Use basis textbook for at most 1 in 20 sentences. Omit what you cannot retrieve support for. `updated` = 2026-11-03. Do not set `review`. `terminology`: omit. Do not edit any file outside this batch dir; do not git commit; do not touch interactions.
Search budget: HARD CAP of 9 WebSearch calls for your item (the whole session shares 200). Use mode "extended" for broad NHS-style queries (about / who can take / side effects / pregnancy-breastfeeding / interactions-alcohol / common questions), standard for narrow ones. Exact page-title queries ("Doxycycline - NHS") give cleanest single-source summaries. WebFetch is blocked; do not try. Attribute a sentence to a URL only if that page's own excerpt carries it; say in `note` if the search blended pages. Search tool is deferred: load with ToolSearch query "select:WebSearch" first.
Entity field notes: `category` = "antibiotics" or "urology-mens-health"; categories [same]; `drugClass` = class id; `class` = words; `routeIds`/`dosageFormIds` from data/content/vocabularies.json; `brands` {"UK":[...],"US":[...]} only names the sources give; `regulatory` UK entry with source {title,url,section?,jurisdiction:"UK",type:"regulatory"} (status prescription unless sources say otherwise); anatomy organs/systems only from: organs brain,eye,ear,nose,tongue,larynx,trachea-bronchi,lungs,heart,aorta,oesophagus,stomach,small-intestine,large-intestine,liver,gallbladder,pancreas,kidneys,bladder,ureters,prostate,testes,penis,uterus,ovaries,vagina,vulva,breasts,skull,spine,pelvic-floor; systems skeleton,joints,teeth,muscles,heart,arteries,veins,nervous,sensory,respiratory,digestive,urinary,reproductive,endocrine,lymphatic,skin,reproductive-female. conditions/symptoms/tests/related/physiology/terms: only ids that exist (check content/conditions.json, symptoms.json, tests.json, medications.json, physiology.json, terms.json via grep/python; leave empty rather than guess). `related` may name existing medicines (amoxicillin, azithromycin, clarithromycin, ibuprofen, etc.) - other batch medicines (doxycycline, flucloxacillin, co-amoxiclav, metronidazole, nitrofurantoin, trimethoprim, tamsulosin, finasteride) may NOT be listed in related/medications fields of other entities unless they exist in the fragment; leave them out (the maintainer cross-links later). references: >=4, >=2 publishers, one official, titles like "NHS: Doxycycline" with section where useful; only URLs the search actually returned.
Class plan: doxycycline owns class `tetracyclines`; metronidazole owns `nitroimidazoles`; nitrofurantoin owns `urinary-antibacterials` (trimethoprim will also use it; do not list trimethoprim yourself); tamsulosin owns `alpha-blockers`; finasteride owns `5-alpha-reductase-inhibitors`. flucloxacillin, co-amoxiclav use existing `penicillins`; trimethoprim uses `urinary-antibacterials` (does not write the class).
