ANATOMY NEXUS - PRODUCTION LOGO PACKAGE

Approved concept preserved: AN geometric monogram + anatomical pathway + wordmark.

OFFICIAL COLORS
Deep Navy  #0B2D45
Soft Teal  #4E9CAB
Cool Gray  #A7B3BD
Light      #F7F9FB
Black      #000000
White      #FFFFFF

DIGITAL
SVG files are true vectors. PNG files use transparent backgrounds except app-icon tile files.
Source/Anatomy-Nexus-Logo-Master.svg keeps the wordmark as editable live text.
Source/Anatomy-Nexus-Logo-Master-Outlined.svg converts the wordmark to vector paths and has no font dependency.

TYPE
Master wordmark uses Inter Display Medium. The outlined master is recommended for handoff and production.

PRINT
Print-CMYK contains process-CMYK PDF/EPS exports generated from the vector master. Final press conversion should use the printer's requested ICC profile when one is supplied.
Approximate process equivalents before profile conversion:
Deep Navy: C84 M35 Y0 K73
Soft Teal: C54 M9 Y0 K33
Cool Gray: C12 M5 Y0 K26

ILLUSTRATOR
Source/Anatomy-Nexus-Logo.ai is a PDF-compatible Illustrator vector source: it contains only vector paths and opens in Adobe Illustrator for editing. The SVG/EPS masters are included as additional Illustrator-safe interchange sources.

FIGMA
A native .fig file is proprietary and requires export from Figma itself. Source/Anatomy-Nexus-Figma-Import-Outlined.svg is the Figma-ready master: import it directly into Figma; all logo shapes and outlined wordmark remain editable vectors.

FAVICON
Includes 16/32/48 PNG, multi-size favicon.ico, SVG favicon, Apple 180px, Android 192/512px, and site.webmanifest.

GEOMETRY
The approved AN concept was rebuilt with explicit vector paths and clean geometric primitives; no bitmap image is embedded inside SVG/PDF/EPS/AI production files.
