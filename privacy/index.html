    Privacy

    What this site records when you use it, what it does not, and what you can do about it. This page describes the behaviour of the code as deployed; it was checked against the implementation on 6 October 2026.

    No accounts, forms or personal data

    Anatomy Nexus has no user accounts, no comment or contact forms and no newsletter. Nothing you type into the site is sent to us: the search box and the drug interaction checker run entirely in your browser against data files downloaded from this site. The only way to write to us is the public issue tracker or a private repository advisory, described on the contact page.

    Page analytics (Google Analytics 4)

    The site loads Google Analytics 4 (measurement id G-W35QT71BH2) to count page views. Our code reports every page as origin + path only: the query string and the fragment are removed before anything is sent, so a search term (/search/?q=…), a list of medicines on the checker (?drugs=…) or a selected structure in the 3D explorer (#s=…) is not included in the page address or the referrer we pass to the tag, including after the address changes while you use a page. Google signals and advertising personalisation are switched off in our configuration.

    The checker sends a few counting events to the same tag: that the checker was opened, how many medicines were added or removed, how many pairs were checked, the highest severity tier of the result and the result state (for example "no matching record"). These events never contain medicine names. The 3D explorer loads no analytics at all.

    Google Analytics sets its own cookies (_ga, _ga_…) to recognise a returning browser and processes the data on Google's servers under Google's terms; we do not control that processing and have no access to raw data about individual visitors. Two behaviours of the tag are configured in the analytics account rather than in this site's code and cannot be verified from the code alone: "enhanced measurement" (which can record outbound link clicks, including the address of a cited source you open) and the retention period of the data. If you want no analytics at all, a content blocker or your browser's tracking protection stops the tag; the site works identically without it.

    What stays in your browser

    • Theme: your light or dark choice is saved in this browser's local storage as atlas-theme.
    • 3D model quality: your choice of the standard or lighter model is saved as atlas-quality.

    Nothing else is stored, and neither value leaves your browser.

    Sharing a check or a search

    The checker and the search page put your current medicines or search term in the page address so that you can bookmark or share it (for example /tools/drug-interaction-checker/?drugs=warfarin,ibuprofen). That address is only shared if you copy it, but it is saved in your browser history and, like every address you request, appears in the access logs of the server that hosts the site. If a medicine list is sensitive to you, clear the list before leaving the page or open the checker in a private window.

    Server logs

    The hosting provider's web server records the addresses requested, the time, the browser identification string and the IP address of each request, as web servers do; we do not have a published retention period for those logs and will add one here when it has been confirmed. We do not add any logging of our own and the site has no server-side code.

    Third parties

    Apart from Google Analytics, every file the site uses (scripts, styles, fonts, 3D data) is served from this site's own address. The 3D atlas is embedded on article pages only after you choose to load it. External sources cited on each page are ordinary links to other organisations' websites, which have their own privacy practices.

    Children, health data and advice

    The site is educational and is not designed to collect data about anyone's health. If you ever share health information with us by mistake in a public issue, tell us and we will remove it from the thread.

    Changes and contact

    This page changes when the behaviour of the site changes; the version of the site is shown in the footer and the full history is in the project repository. Questions about privacy can be raised through the routes on the contact page.
