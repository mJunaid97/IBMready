Corrections policy

Medicine changes and mistakes happen. Here is how we handle them.

Reporting an error

If you find a factual error, an outdated statement, a broken source link or a misleading page, please tell us. Quote the page address and, if you can, the source that supports the correction. Reports from clinicians and educators are especially welcome.

What happens next

  1. The report is checked against the page's cited sources and, where needed, against current official guidance.
  2. A confirmed error is corrected in the content, the page's last-updated date is changed, and the correction is recorded in the release changelog.
  3. Safety-relevant corrections (first aid, medicines, when to seek care) are released as soon as they are verified rather than waiting for the next scheduled release.
  4. If an entire page is withdrawn, its address returns the correct gone status rather than a misleading page.

Version history

Every release of the site is numbered and archived, so the content of any earlier version can be inspected. The roadmap and changelog list what changed in each release.
